# RE3 대사 검수 — 2026-10-27

Claude Code의 중단된 검수를 이어 진행했다. 원래 806개 대조표 중 첫 묶음의 수정 후보를 적고 `싶·님` 글자를 추가하던 중 사용량 제한으로 멈췄으며, 후보는 rooms.json에 적용되지 않은 상태였다.

## 범위와 결과

- 112개 방 표, 총 1,048개 메시지 슬롯을 확인했다. 일본어 OCR·한글 대조표 806개(텍스트 슬롯 934개)를 끝까지 읽고, 장면의 앞뒤 대사와 말투를 다시 검토했다. 빈/제어 전용 슬롯 114개도 별도 목록으로 남겼다.
- 36개 메시지에 수정 37회를 적용했다. 감시원/조사원은 감시원으로 통일했고, `알고 싫은→알고 싶은`, `대담해→대답해`, 머피의 물 대사, 감염 장면, 주유소의 소리 설명, 부자연스러운 저장고 설명 등을 고쳤다.
- `줄→좋`은 번역의 문제와 별개로 이전 커밋 e78e473에서 EE35 대응표를 고친 내용이다. 현재 소스와 다시 만든 HD 글꼴에서 줄로 대응한다.
- 필요한 `싶·님·답·밸`을 비어 있던 ED00–ED03에 추가했다. SD는 기존 패치 글꼴의 조각을 조합하며, HD는 기존 Noto 글꼴로 그린다. 네 SD 글자 모양을 이미지로 확인했고, 다른 글자 픽셀/비트 필드/그래픽 파일 런이 보존되는 검사도 통과했다.
- 모든 수정 메시지의 타이밍·페이지·선택·종료 제어 코드와 줄바꿈을 원본과 대조했다. 단계별 인코딩도 확인했다. 실행 DLL은 바꾸지 않는다.

## 근거와 보류 범위

일본어 근거는 게임 ROFS의 원본 RDT다. 기존 검수 스크립트가 112개 표의 체크섬을 대조한 뒤 그린 이미지와 OCR을 재사용했다. 수정 후보 중 판독이 불확실한 문장은 이미지를 직접 확인했다. 948장 전부를 새로 육안 전사한 것은 아니다. 029_05의 OCR 공백은 원본 029_06과 같은 오프셋을 가리키는 중복 슬롯이어서 생겼다.

영어는 [Saiyuki12의 전체 대본](https://gamefaqs.gamespot.com/ps/198459-resident-evil-3-nemesis/faqs/60207)을 관련 대사·장면의 보조 근거로 사용했다. 이 대본에는 조사 문구와 표지판 전체가 없으며, 설치본에도 영어 RDT 말뭉치는 없다. 일본어와 영어의 현지화 차이는 무조건 오역으로 취급하지 않았다. 마지막 S.T.A.R.S. 대사와 일부 주유소 표현은 영어판 표현을 유지한다. 질→니콜라이의 기존 반말과 질→미하일의 존댓말도 구분했다.

합성 장치의 로마 숫자·특수 메뉴 글자와 선택지 배치는 평탄화된 OCR만 보고 바꾸지 않았다. 게임 재시작 후 글자 크기, 줄 넘침, 타이밍을 확인해야 한다. 문서·그림 전체의 재전사는 이번 범위가 아니다.

전체 슬롯 목록, 각 검수 항목 및 수정 전후 문장은 [JSON 기록](dialogue-review-20261027.json)에 있다.
